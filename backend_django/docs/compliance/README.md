# Compliance documentation

- [`SOC2_ISO27001_mapping.md`](./SOC2_ISO27001_mapping.md) — mapping of
  MyCyber DLP's implemented controls to the AICPA SOC 2 (TSC 2017) Trust
  Services Criteria and ISO/IEC 27001:2022 Annex A controls, with code/test
  evidence references into `backend_django/`.

See also the project-level [`../../SECURITY_ARCHITECTURE.md`](../SECURITY_ARCHITECTURE.md)
for the full architecture, data-store and egress description.

These artefacts are produced to support SOC 2 Type I and ISO 27001:2022
readiness. Coverage is **mapped** (implemented + evidenced) where tests exist,
and **partial/operational** where the control is procedural.
